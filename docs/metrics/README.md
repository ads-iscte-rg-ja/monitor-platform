|---|---|
| `baseline/` | Iteração 0: lint, cobertura, Sonar, acoplamento e carga **antes** de qualquer alteração |
| `iter-N/` | Mesmas medições depois da iteração N |

Os scripts de análise geram as tabelas LaTeX diretamente para `../../report/gerado/`.
